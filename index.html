Results come from the free, public-domain openfootball feed on GitHub, which a local web page is allowed to read. It is community-maintained and refreshed roughly once a day, so it tracks completed matches rather than minute-by-minute live scores. The FIFA scores page cannot be read by a file on your computer (it loads its data with JavaScript and blocks cross-site requests), but you can paste any JSON feed below, including your own proxy of FIFA.
